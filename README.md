# Basic Python Projects

These are basic projects written in Python. They use various modules such as tkinter or sqlite3.

## Projects:

- [Web Page Generator](#web-page-generator)
- [Django University](#django-university)
- [BlueBird Banking](#bluebird-banking)

## Web Page Generator

This project is a Python GUI application that allows the user to enter custom text and generate an HTML web page. The generated web page can then be opened in a web browser.

## Django University

This project is a Django web application that manages university information. It uses Django models, forms, migrations, URL routing, templates, and the Django administration interface.

## BlueBird Banking

This project is a Django banking application that allows users to create accounts, make deposits and withdrawals, and view their account balances and transaction history.
